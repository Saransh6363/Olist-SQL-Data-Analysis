# 📊 Olist SQL Data Analysis

## 📌 Project Overview

This project analyzes the Olist E-commerce dataset using MySQL to discover business insights related to sales, customers, products, payments, and order performance. It demonstrates SQL querying, data exploration, and business analysis on a real-world dataset.

---

## 🎯 Objectives

- Analyze sales performance
- Study customer purchasing behavior
- Identify top-selling products
- Analyze payment methods
- Generate business insights using SQL

---

## 🛠 Skills Used

- MySQL
- SQL Queries
- JOINs
- GROUP BY
- Aggregate Functions
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Data Analysis

---

- Orders
